Public convert_result(view, command.expectation, config=configuration) must succeed; compare complete normalized payload_json bytes. Validate exact job/result ID public grammar. Duplicate(profile_id,result_id) or duplicate job binding refuses. Full profile snapshot/command/ownercontext/result/config/output bind the entry. Receipt/explanation/diagnostic preparation happens here, never on dispatch or via hidden network callbacks.

Reconstruct/copy exact typed records; validation must not mutate nested caller records through __post_init__. Do not trust forged frozen instances or caller-derived counts. Cache only immutable canonical ASCII bytes, exact derived projections and immutable identity/permission records; do not retain mutable producer dicts or secret credentials. Explicit maximum per-artifact/depth/node/manifest/aggregate accounting is inclusive. Aggregate includes complete producer, every supplied report, cached quality summary and manifest bytes; metadata not counted is explicitly outside this logical bound. Constructor error precedence: exact owner types/permission/profile identity -> public conversion/config binding -> report semantic binding -> canonical limits -> duplicate and aggregate admission. Missing optional reports are permitted. Product/owner errors are fixed codes; full internal graphs never cross wire.
