## Operator API

Install the service wheel using its pinned dependencies and Python3.12. The `duckdb` extra additionally selects the accepted DuckDB adapter. Registry publication is not authorized; source development installation currently uses `python -m pip install packages/service` after installing the accepted local SDK/core dependencies. Fresh release wheel/sdist qualification remains pending.

The public module exports `Scope`, `DatasetIdentity`, `RawRead`, `RawDataset`, `FeatureDataset`, `Credential`, `Grant`, `Limits`, `Ledger`, `Service` and `WireError`. Supply one shared `Ledger` to every controller. It requires an explicit trusted integer UTC-nanosecond clock, finite limits, credentials, grants, datasets, policy revision and registry digest; there is no permissive default registration or remote configuration API. Credentials hold a SHA256 digest of an operator-provisioned opaque random bearer token. Use `secrets.token_urlsafe(32)` in owned qualification; never put tokens in examples, logs, query strings or tracked files. Syntax cannot prove operator token entropy.

`RawDataset` receives a complete native `RawRead` baseline and a trusted server callback `(Cancellation | None) -> RawRead`. Its admitted column vocabulary and exact instrument/session/half-open scope are fixed. It freezes complete native content and the actual receipt digest, retains only metadata and encoded size summaries, and repeats the same read before projection. Receipt/content changes fail closed. `DuckDBSource(adapter, request)` explicitly admits one bounded native AcquisitionRequest by performing an initial read. `source.read(cancellation)` repeats that exact request through the accepted parameterized adapter. HTTP correlation never replaces the stable server request ID. Full canonical mapped source identities are preserved; chunk/catalog aliases are insufficient. Cancellation is cooperative through native file/query/fetch/mapping checks, not hard preemption or a sandbox for trusted local callbacks.

`FeatureDataset` receives an already produced native FeatureResult, its original producer context/command digest, full dataset identity and exact producing scope. SDK validation precedes immutable payload storage. Requests project approved columns/quality/evidence without recomputation, retiming or rewriting executed features/context/metadata. Full exposed native feature vocabulary requires authorization. Derived reading and retained producer payload require explicit rights; local capabilities do not establish rights.

`Grant` binds principal, dataset ID/revision, policy revision, exact scope, columns/actions and independent validity. `Ledger.revoke(grant_id)` removes authority immediately at the next admission/cancellation/visibility check. Token expiry produces authentication denial; grant/dataset expiry or revocation produces authorization denial. Unknown principals/grants/datasets/columns/source identities fail closed.

## HTTP and wire boundary

`Service(ledger)` is a WSGI callable supporting `POST /v1/request`, exact `application/json`, Content-Length and header bearer authentication. Discovery and bounded slice operations only. Foreign peers, multiprocess WSGI, query strings, transfer encoding, malformed/duplicate JSON, unknown versions, uploaded selectors/objects, executable values, pagination and other operations are denied. Body16KiB, response256KiB, native100rows,64raw columns,39feature vocabulary,16datasets,16credentials,64grants, maximum60attempts/accounting interval; transfer and interval bounds must be explicitly configured below their policy ceilings. These are finite algorithm/data bounds, not process RSS/CPU guarantees or denial-of-service certification.

Raw wire1.0 preserves exact native metadata with int64/UTCns decimal strings, finite binary64 bits, decimal128 coefficients, nulls and explicit record/list tags. Native feature projections require explicit1.1 `feature_slice` wrapping the original complete producer result. No implicit version upgrade. The1.1 outbound record vocabulary includes native QualityRow needed inside structured interval values;1.0 schema remains unchanged. Closed JSON schema is supplemented by duplicate-key, finite-value, surrogate, depth/node and semantic checks. No wire tag constructs Python objects on request ingress.

Each attempt consumes shared rate allowance. Expected response capacity is reserved before source reads; concurrent prepared responses retain reservations until visibility or `close()`, including across accounting windows. Actual emitted bytes consume shared principal/global transfer allowance, including errors. Once an error cannot fit,429 emits an empty body. Reservation is capacity, not a refund of consumed rate/transfer. Source failures are redacted. Successful and source-failure responses reauthorize before the first and only bounded output chunk. Headers and chunk authorization occur under the shared ledger lock; already authorized network bytes cannot be recalled. Discovery vocabulary is rebuilt at this point after revocation. Controllers must close abandoned iterables.

`equity_feature_service.loopback.qualification_server(service, host='127.0.0.1', port=0)` is an explicit synchronous stdlib test host accepting only loopback binding. Duplicate Authorization is denied; access logs are suppressed. No external service, production TLS/identity issuer, job execution, physical retention/cache, durable multiprocess quotas or production SLO is delivered here. Later R7 stories remain separately admitted.
