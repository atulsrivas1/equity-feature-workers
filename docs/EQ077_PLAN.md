It owns service authentication, authorization, HTTP framing, approved slice registrations and bounded response conversion; it is optional and never a dependency of calculation or I/O packages. Canonical87 owns lifecycle; a companion PR supplies implementation/build evidence without a duplicate issue. Use explicit server-owned registrations, never caller imports, executable objects, paths, SQL, credentials or destinations.

Implement a synchronous WSGI JSON endpoint for raw transport1.0 `slice` and authorized `discover`, plus an explicitly advertised transport1.1 representation for native feature slices. Every request selects immutable dataset/source/input/snapshot/mapping identities, one approved instrument/session, a half-open int64 nanosecond range and approved logical column/feature names. It does not invoke calculations or worker jobs: those are EQ078. Feature slices are projections of explicitly admitted immutable precomputed native results; selecting a feature does not execute it or confer derived-read rights. Raw and feature datasets have separate action rights and registration kinds. Discovery returns only actually approved metadata and feature/algorithm pairs allowed to the current principal, never another user's job/results or paths. Unsupported operations reject before component construction.

Use public accepted DuckDB acquisition interfaces for an actual synthetic raw source. Its fixed SQL binds instrument/time values as parameters. Service orchestration contains no backend SQL and supplies typed bounded acquisition requests. Feature qualification uses explicit owned native FeatureResult fixtures and the same result validation/provenance rules; it makes no claim about remote asynchronous production or scoped job-result delivery. Adapter callables are trusted operator code in a supplied registry, not a sandbox. Qualification must show denial occurs before invoking a source and that source results cannot alter pinned dataset/scope/column/metadata identities.

## Identity and scope rules before code

The initial authentication mechanism is explicitly provisioned opaque bearer tokens: server configuration maps fixed cryptographic token digests to opaque principals with validity intervals. Tokens must have at least256 bits of operator-provided random entropy; tests use generated ephemeral tokens and never publish them. Use constant-time digest comparison, exactly one Authorization bearer credential, bounded header length, and no query-string credentials. Tokens and caller payloads never enter logs, audit artifacts or error strings. This is local synthetic identity qualification, not OAuth/issuer production admission. A qualification server binds only loopback; externally trusted TLS/identity provisioning remains EQ084 and requires operational authorization. Do not trust forwarded headers to claim TLS or principal identity.

Server grants pin principal, grant/policy revision, admitted dataset identity and immutable allowed instrument/session/time/column/feature scope. Require raw_read for raw slices, derived_read for precomputed feature slices, discover for discovery and appropriate source dataset rights. Grants cannot enlarge dataset rights. Unknown scope/revision/feature, foreign principal, expiry at equality and revoked grant all deny with the same fixed redacted authorization error. Times use trusted integer server UTC nanoseconds, half-open validity intervals and exact int64 bounds; client clocks cannot authorize. No new mathematics, unit conversion, coverage inference, ConfigSpec digest or algorithm revision.

Reject duplicate/unknown fields and noncanonical scalar encodings using the exact explicitly requested supported wire schema and semantic checks. Accepted closed1.0 raw schema bytes remain unchanged; feature projection through1.0 rejects rather than dropping fields or silently upgrading. A packaged codec must be exercised from an installed wheel and sdist; the earlier tool reference alone is not runtime qualification. Preserve native fields, exact int64/ns, floating bit patterns, scaled-price/decimal units, metadata, null validity, quality and actual feature/algorithm identity. For sliced source inputs, reject off-scope/out-of-order/inconsistent batches instead of silently discarding an unsafe producer result. Feature projection preserves entities/quality/evidence and full native metadata. Each response reflects the actual supplied immutable source facts, not invented complete coverage or future known-at values.

## Bounds, concurrency and visibility

Enforce policy maxima immediately for implemented operations: request16384 bytes, response262144 bytes, input100 rows/1048576 bytes, one instrument/session, at most39 approved features, existing defensive parse limits. Start with one nonpaginated bounded response: cursor must be null; oversize output denies, never silently truncates or advertises unimplemented paging. Later paging requires the separately versioned design anticipated by EQ076. Required finite limits and a trusted clock are startup inputs, not permissive defaults.

Request attempts and transferred bytes use an explicitly shared single-process principal/global ledger:60 requests per fixed60-second interval, principal1048576/global2097152 transfer bytes. Count failed requests, retries and cache-free repeated fetches; constructing a second controller cannot reset the supplied ledger. Reject multi-process WSGI operation in this first profile; durable multi-instance accounting, cache, audit persistence, process CPU/RSS and full job resource budgets remain EQ080/084. No unbounded source factory construction or acquisition before scope admission. Reserve/settle transfer capacity under the same shared synchronization as current grant checks, without refunding consumed allowance.

Reauthorize at source admission, bounded producer/chunk boundary and final visibility. Grant revocation and final authorization/response visibility must have an explicit shared lock and linearization point: a concurrently revoked grant cannot publish a new response after revocation wins. Source work occurs outside the authorization lock with no partial response exposed. Verify the race with barriers, not sleeps. A completed authorized response is a historical fact; logical expiry does not claim physical source deletion, backups or hard preemption. Revocation/expiry blocks subsequent reads. Invalid clocks fail closed.
