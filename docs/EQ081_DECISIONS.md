## Proposed immutable public surface

RemoteClient(origin, token_provider, timeout=3.0, attempts=1, retry_delay=0.1, budget=15.0, ssl_context=None) is a synchronous explicit caller-owned transport. Context manager/close have no hidden executor or polling thread. Timeout finite>0<=5, attempts integer1..3, delay finite0..5, budget finite>0<=15. Custom SSL context must retain CERT_REQUIRED and check_hostname; no verification bypass. Token provider invoked only after local request validation, once per attempt, returns exact ASCII [A-Za-z0-9_-]{43,256}. No credential storage in public result/error repr, exception cause/context or logs. No ambient proxies/netrc/environment token lookup, redirects, untrusted path or cross-origin followup.

Request(version, request_id, payload) owns canonical validated bytes copied from input; later caller mutation cannot change retry bytes. Payload closed JSON data only. Helpers discover, slice_raw, slice_features, calculate, job_status, job_cancel, result_read and artifact_read construct this request and expect the matrix above; calculate recomputes command_digest from operation/context/scope excluding command_digest/idempotency_key, matching accepted server definition. Caller supplies stable idempotency_key explicitly. Known job commands/config/context are pinned immutable caller expectations, not learned from an untrusted discovery response.

DiscoveryView/RawSliceView/FeatureSliceView/JobView/ResultView own bounded immutable response bytes with fresh decoded JSON access. Views expose the actual transport version and request correlation. RawSliceView.to_batch requires native extra and exact pinned dataset/scope/ordered column inventory, public CanonicalBatch/Column/BatchMetadata and validate_batch; missing required fields deny conversion, optional absent fields remain absent. FeatureSliceView remains a projection with selected/executed inventories separate. ResultView.to_result requires full pinned context, command digest and executed feature inventory, reconstructs complete public producer records, validates context-to-metadata/source/backend/config/quality/evidence invariants, and uses independent frozen native bytes for qualification. No wire receipt/acquisition proof or native classes from arbitrary labels. Artifact result stays in memory; filename must equal result-SHA256(ASCII opaque result_id).json and no automatic local file write.

Light client uses standard-library http.client/ssl plus exact accepted jsonschema validator dependency set. Native extra adds accepted equity-feature-contracts and equity-feature-io-sdk0.1.0a2. No client runtime dependency/import of service, workers, concrete adapters/sinks or calculation package. Client version0.1.0a0 in packages/client; package/build selectors and qualification provenance must acknowledge client inputs separately, not alter accepted runtime archives.

## Concrete framing, denial and retry policy

Fixed origin path /v1/request; origin has no path except empty or /, userinfo, query or fragment. HTTPS default verified trust, HTTP only literal loopback (no localhost DNS expansion). POST application/json, explicit single Authorization/Content-Length, request16384 inclusive. Response262144 inclusive, exactly one decimal Content-Length, no Transfer-Encoding or Content-Encoding, one exact application/json Content-Type, Cache-Control no-store, X-Content-Type-Options nosniff. Reject duplicate critical headers, redirect statuses, missing/oversize/truncated/extra bytes, empty protected200 or unexpected attachment. Response framing ends at its declared length; close connection without reuse. Do not infer absence of trailing bytes from a bounded read: qualification must freeze the exact extra-byte rejection mechanism before Ready.

Successful version/request_id/kind exactly match request expectation. Correlated error version and nonnull request_id must match. The only permitted null-correlation exception is version1.0 kinderror with exact closed tuples:401/authentication/unauthenticated;403/authorization/not_permitted;429/quota/quota_exceeded;500/internal/internal_error;400/transport with invalid_schema, invalid_json, incompatible_version or bounds. These accepted codec/late failure paths do not constitute server receipt or successful result proof. Freeze each tuple against actual schema/source and adversarial fixture before Ready; anything else fails protocol. Closed error retryable must be false for accepted server, whose _error always sets false. No server-error automatic retry, including429/500; future retryable=True is not silently enabled. Read retry policy therefore applies only explicit transport disconnect/timeout/incomplete framing before exposing any successful object, never schema/integrity/TLS certificate/auth failure. Mutations are never replayed; interrupted possible-send outcomes use outcome_unknown, and no hidden cancel/refund/recovery claim. Invalid framed JSON does not retry. No Retry-After-driven automatic replay; unsupported/ambiguous header never expands attempts or budget.

Each attempt uses unchanged request/correlation and a fresh provider call. Bounded monotonic budget checked before provider/network, after provider, each read and before exposing result. Decrease per-call socket timeout to remaining budget; no hard DNS/OS wallclock guarantee. Transport failures close the connection before any explicit read retry, delays bounded by remaining budget. If caller/provider raises or TLS verification fails, stop and sanitize without retaining secret exception graph. Fault fixtures must prove actual cleanup, not merely matching implementation mocks.
