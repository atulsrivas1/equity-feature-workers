## Design and identity

Deliver immutable validated `InputManifest`, `TaskManifest`, `ClaimIdentity` and `OutputManifest`, a closed canonical task wire representation and deterministic task digest. Worker package becomes experimental `0.1.0a2`; keep exact SDK `0.1.0a2` and canonical contracts/features `0.0.4a4`. Only explicit public imports; no dynamic executable loading.

Task boundaries bind job/generation, feature family and ordered compatible feature IDs/algorithm versions, governed ordered sessions and instrument/shard IDs, source snapshot/revision/mapping and canonical input identity digests, configuration/math/schema/package versions, cutoff/availability policy, initialization/warm-up/state identity, and logical destination ownership. Lists use immutable tuples, duplicates are rejected and order remains significant. Callers may partition independent instruments; manifest validation does not certify arbitrary mathematical partitioning. Continuous quote merge is unsupported. A requested merge requires explicitly supplied qualified capability identity; no implicit permission from a batch API.

Input state distinguishes missing, supplied empty and partial/complete coverage; unknown known-at stays null. Record canonical acquisition identity rather than creating another input schema. Coverage declarations do not prove source truth. Reuse scopes bind revision/mapping, market/reference/decision cutoffs, availability, configuration and initialization; different scopes must not share acquisition caches. A task records positive bounded input batch/byte budgets, not a materialized dataset or unrestricted cache.

Timing uses exact signed int64 UTC nanoseconds; reject bool as integer. In known_at causal mode C<=E and K<=E; reconstruction preserves canonical supplied timing/reason. Session bounds are supplied, ordered, nonoverlapping and nonempty. Market events remain [open,C), canonical completed-bar/closing-auction exceptions unchanged. History order and required supplied warm-up/state identity are explicit; missing initialization cannot be labeled ready. No wall-clock substitution or new numerical equation. Price scales, units, nulls, quality and actual canonical mathematics remain owned by calculation/I/O contracts.

Use ASCII JSON with sorted keys, no whitespace/BOM/newline, ensure_ascii and no NaN/Infinity, reject controls/lone surrogates and unknown/extra fields. Signed int64 uses the accepted tagged decimal representation. Worker task digest is SHA256 over domain `efworker-task1` + NUL + exact canonical task bytes. This is a worker identity, not the sink idempotency key. Same task/content retry preserves digest; changed input/config/cutoff/destination/initialization produces another task identity. Operational claim owner/attempt/lease timestamps are excluded from deterministic task identity. Claims record identity only here; durable acquisition/retry/resume/cancel belongs to EQ063.

`OutputManifest` embeds existing `PublicationEnvelope` and an optional existing `CompletionReceipt`; it binds the task digest and validates job/generation/partition/destination and declared versions. Descriptor metadata must match task input/config/timing/feature identity. Completion requires recomputed SDK idempotency key, exact identity/content/count equality and a committed receipt; no success from staged files, claim state or a caller-created timestamp. Output preserves canonical schema/count/hash/quality/availability/provenance through existing descriptors and receipt; no duplicate codec or sink protocol. Manifest admission is structural, not a new correctness/PIT/durability certificate.
