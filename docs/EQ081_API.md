## Data types and exact signatures

All public records below are frozen, validate exact field types and copy concrete sequences to tuples. IDs/digests and nested wire objects use the accepted bundled schema constraints; booleans never substitute for integer bounds. JSON inputs are canonicalized and validated into immutable owned bytes at construction. Mutable caller mappings cannot alter requests, expectations or repeated attempts.

- DatasetKey(dataset_id:str, revision:str, snapshot_id:str, mapping_version:str, source_id:str, input_id:str): complete original source identity, no truncation/suffix normalization.
- ScopeKey(instrument_id:str, session_id:str, start_ns:int, end_ns:int): exact signed int64 start<end; emitted signeddecimal strings, never datetime or float.
- FeatureRef(feature_id:str, algorithm_version:str): exact ordered feature inventory, no duplicate IDs.
- RawExpectation(dataset:DatasetKey, scope:ScopeKey, data_kind:Literal['trade','bar','quote'], columns:tuple[str,...]): requested actual field inventory/ordering. Raw response contains no data_kind; caller must pin it. Required schema columns govern native conversion, not a guess from names.
- ProducerExpectation(context:Mapping[str,object], scope:ScopeKey, executed_features:tuple[FeatureRef,...], backend_id:str, backend_version:str): owns complete validated context bytes, recomputes SHA256 of canonical operation=calculate/context/scope and exposes command_digest. Pins namespace/mathpolicy/configidentity+digest/availability/source/session/full actual feature inventory and backend independently of response. Context's requested features must be a subset of explicit full executed inventory with exact versions, not fabricated from returned payload. No raw/native receipt, TTL or rights proof is inferred from omitted fields.
- JobExpectation(job_id:str, command_digest:str): opaque owner job ID and admitted command, states remain actual closed schema values.
- Request(version:Literal['1.0','1.1'], request_id:str, payload:Mapping[str,object]): owns validated canonical request bytes; maximum16384. Operation is exact accepted closed request schema. Public .encoded returns immutablebytes; .payload_json() returns a fresh independent mapping.
- Failure(category:Literal['configuration','credentials','transport','protocol','authorization','contract','quota','internal','capability','client','unknown'], code:str, phase:Literal['prepare','provider','connect','send','read','decode','convert'], status:int|None): code must be a closed client code listed below, never caller/server text. This is an inert value, not BaseException; no cause/context/traceback/socket/provider/client/body/token references.
- Outcome[T](view:T|None, failure:Failure|None): exactly one present, immutable; .ok derives from failureabsence. No implicit unwrap raising exceptions or success coercion.
- DiscoveryView,RawSliceView,FeatureSliceView,JobView,ResultView: own bounded validated immutable response bytes; .encoded and .payload_json() return originalbytes/fresh mapping. View types reflect operation/kind/version; projected view remains distinct from complete result. JobView contains actual coarse state and pinned command. ResultView stores validated controlled filename only for artifact_read, no path/write method.

RemoteClient(origin:str, token_provider:Callable[[],str], *, timeout:float=3.0, attempts:int=1, retry_delay:float=0.1, budget:float=15.0, ssl_context:SSLContext|None=None).
